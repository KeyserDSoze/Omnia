# Omnia — competitor landscape (research: 2026-11-17)

| Product / project | Relevant capability | Differentiation opportunity for Omnia |
|---|---|---|
| [OpenClaw](https://github.com/openclaw/openclaw) | Tool-using, cross-channel personal agent | User-owned event normalization, SaaS tenancy and auditable memory timeline |
| [Omi](https://www.omi.me/) | Wearable audio capture, transcription and memory | Cross-provider data catalog + evidence-linked personal reflection |
| [Personal AI](https://www.personal.ai/) | Long-term personal memory and AI persona | Auditable consented actions and standard canonical event schema |
| [TwinsMem](https://github.com/twinsmem/twinsmem) | Open-source personal AI / digital twin memory | Production-grade Azure + local adapter parity, mobile-first UX |
| [Companion Memory](https://docs.ci.computer/docs/companion-memory/install-and-use) | Private digital twin database / life logging and MCP context | SaaS option with portable user-controlled archive |
| [OwnOrbit AI](https://github.com/WGJ-Fry/ownorbit-ai) | Self-hosted personal agent and private second brain | Easier multisource ingestion and personalized coaching with consent |
| [Plaud](https://www.plaud.ai/) | Recording and meeting intelligence hardware | Broad open standard integrations, not proprietary hardware dependence |

This is a directional comparison, not a verified exhaustive feature or pricing audit. Some products offer partial overlaps rather than full digital twins. Re-check product status, platform terms, user reviews, costs and privacy terms before positioning/launch.

**Differentiator hypothesis:** a *personal data operating layer* that converts source evidence into normalized events, timelines, relationship threads, embeddings and user-editable insights; agents only act through a consented capability boundary. It must not become a surveillance or unconsented impersonation tool.
