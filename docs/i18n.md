# Lingue (i18n)

Decisione: [ADR 0103](../adr/0103-internationalization-21-languages.md).

## Come funziona

- Codice in `src/mobile/src/i18n`: `locales.ts` (elenco, nome nativo, tag BCP 47, direzione),
  `index.ts` (store, `t()`, `useT()`, `useLocale()`, `setLocale()`) e `messages/<codice>.ts`.
- L'italiano è il catalogo sorgente. Gli altri sono tipizzati `Messages`: una chiave mancante non compila.
- Lingua scelta: `localStorage` `tao.locale`, poi `navigator.languages`, poi inglese.
  Non viene inviata al server né salvata nel database.
- Parametri `{nome}`; plurali con `Intl.PluralRules` (oggetti `{ one, few, many, other, ... }`).
- Arabo, urdu e persiano impostano `dir="rtl"` e `lang` sulla radice e su `<html>`.
- Le richieste della chat (`oggi`, `piano`, `nota`, `impostazioni`, `configura`) si riconoscono in
  ogni lingua con le chiavi `intent.*`: parole separate da `|`, `*` finale per il prefisso.
- Il login OIDC passa `ui_locales`.
- Il piano del giorno usa `language` (vedi [assistant.md](assistant.md)).

## Aggiungere una lingua

1. Aggiungila in `locales.ts` e copia `messages/it.ts` traducendolo.
2. Aggiungi codice e nome inglese in `src/backend/Tao.Application/AssistantLanguages.cs`.
3. Esegui `npm run typecheck`, `npm test` e i test Domain (il numero di lingue è verificato).

## Limiti

Le traduzioni non sono state riviste da madrelingua: vanno riviste prima di un rilascio pubblico.
